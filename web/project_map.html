毎朝 7:07 の自動処理

平日の朝（日本時間、火〜土）に、このセッションが自動で起きて順に実行します。期間は 2026-11-12 まで。最後の回で最終結果をまとめます。

  1. 最新版を取得GitHub のブランチに合わせる
  2. ペーパートレードを進める全銘柄の終値がそろった日だけ処理する
    tools/papertrade.py run
  3. 火曜だけ: Claude 口座の判断判断材料（brief）だけを根拠に、変えるか据え置くか
    papertrade.py brief
  4. シミュレーターの実データを更新±25% を超える異常な動きは止める
    tools/export_sim_data.py
  5. 本人の選択を読む「待你决定」で押したボタンを PLAN.md に記録
  6. コミットしてプッシュpaper/ と web/ のデータだけ
  7. ページ 2 枚を更新説明ページとシミュレーター
    tools/build_overview.py
  8. スマホに通知主な口座の成績を 1 行で
