## ★ 最優先の制約: Deloitte independence

証券の購入前に **DESC 確認と事前承認（pre-clearance）が必須**。
これは配分の議論より前に来る制約。買えないものの配分を検討しても実行できない。

```bash
python -m src.cli compliance
```

で確認状況が一覧でき、未確認の銘柄は買い物リストから自動的に外れる。
確認記録は `config/compliance.yaml`（`.gitignore` 済み）。

**このツールは制限対象かどうかを判定しない。** DESC と Independence & Conflicts
Network が唯一の正で、リストは機密かつ更新される。ツールは「確認したか」の進行管理だけ。

### 現状が有利な点

**保有証券がゼロ（100% 円現金）なので、強制売却リスクがない。**
保有中の銘柄が制限対象と判明して損失を出して売る、という最悪のパターンを回避できる。
すべて買う前に承認を通せる、最良のスタート地点。

### 摩擦の分布

選択した配分では、摩擦がサテライトに集中する。

| 部分 | 比率 | 摩擦 |
|---|---:|---|
| インデックス（コア） | 55% | 低 — ファンド自体が発行体 |
| 債券 | 15% | 低 |
| 現金 | 5% | なし |
| **米国個別株（サテライト）** | **20%** | **高 — 1 銘柄ごとに申請** |
| **日本株** | **5%** | **高** |

→ **75% は先に動かせる。25% は承認待ち。**

### Independence に確認すべきこと

1. 広範に分散した投資信託・ETF は事前承認が必要か
2. 必要な場合、銘柄ごとか、ファンド単位で一回か
3. 自分の職位・役割・オフィスで制限の範囲はどこまでか
4. 口座を開く証券会社に制限はあるか（**ブローカー自体が制限事業体の場合がある**）

1 の回答次第でコア 55% を先に動かせるかが決まるので、ここが最初のボトルネック。
