注目アカウントの投稿から、その人の視点で持仓を分析してください。追加の指示: $ARGUMENTS
返答はユーザーが使っている言語で書く（中国語で聞かれたら中国語）。

1. 取り込む。
   - 引数や会話に投稿の本文・URL が貼られていれば、それを `python tools/influencers.py import - --who <key>` に
     標準入力で渡して取り込む（key は config/influencers.yaml の jukan / serenity など）。
   - 貼られていなければ `python tools/influencers.py fetch`（特定の人だけなら `--only serenity`）。
   - どの取得元も使えない（X API・cookie・RSS が無く、FxTwitter も止まっている）と出たら、黙って進めない。
     理由を伝え、X のプロフィール（https://x.com/jukan05 、https://x.com/aleabitoreddit ）から
     最新の投稿を貼ってもらうよう頼んで止まる。Web 検索の断片で本人の意見を組み立てない。
2. `reports/influencers.md` を読む。「取り込めなかったもの」があれば先に伝える。
3. 人ごとに次を書く。
   - **最近言っていること**: 取り込んだ投稿の要点を 3〜5 個。各要点に投稿の日時と URL を付ける。
   - **その人の視点で見たこの持仓**: 「Jukan なら」「Serenity なら」という形で、レポートの「見方」と
     実際の投稿だけを根拠に、触れた持ち株（比率つき。ファンド経由なら どのファンドか）を
     どう評価しそうかを書く。投稿に無い意見を本人の発言として書かない。推測は「推測」と明記する。
     その人の関心の外にある持ち株（例: Netflix、Apple のような消費者向け）は「この人の視点では語れない」と分ける。
   - **その人が見落としがちな点**: lens の blind_spots と、投稿の根拠の強さ（報道の転載か、本人の分析か、
     ポジション公表か）。
4. 最後に視点を戻して判断する（CLAUDE.md の判断基準）。
   - 持仓は 3 本のインデックスファンドで、個別株は透かした結果にすぎない。1 つの投稿で比率を変える理由になるか。
     多くの場合「何もしない」が正しく、そう書いてよい。
   - 短期の材料・推奨銘柄の後追いは、税制・配分・売買を減らすことより根拠が弱いと明記する。
     Serenity の推奨銘柄のような小型株を個別に買う話になったら、独立性の確認（/compliance）が先で、
     購入可と記録されていない銘柄は勧めない。
   - 行動に移すべきものがあれば 1〜2 個。積立の配分の変更を売却より先に検討する。
