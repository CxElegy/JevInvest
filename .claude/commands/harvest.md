課税口座の損出し・益出しを点検してください。追加の指示: $ARGUMENTS

1. **金額を会話で聞き出さない。** ユーザーに手元で実行してもらう:

   ```
   python -m src.cli harvest --realized <今年の課税口座の実現損益>   # 証券会社の「譲渡益税明細」などの数字
   python -m src.cli harvest                                         # transactions.yaml から数える（概算）
   python -m src.cli harvest --pct-only                              # 金額なしで貼りたいとき
   # 課税口座で受け取った配当（源泉徴収あり・株式数比例配分方式）は損と通算されるので --dividends で足す
   # 確定申告で繰り越している過去の損があれば --carryover
   ```

   ユーザーが自分から金額を書いたときだけ、Claude が代わりに実行してよい。
2. 読み解きの順番（CLAUDE.md: 税・手数料 → 配分 → 売買を減らす）:
   - **損出しは多くの場合「税の繰り延べ」** と最初に言う。買い戻すと取得単価が下がり、将来売るときに同じ額を払う。
     出力の「繰り延べの得の目安」が往復コストより小さければ、やらない案を先に出す。
   - **益出し**（今年が実現損のとき）は将来の税がそのまま減る。ただし確定申告で損を 3 年繰り越すつもりなら効果は重なる。
     繰り越すには損が出た年から毎年続けて確定申告が要り、申告した所得は国保などの保険料・扶養の判定に入りうる
     （会社の健康保険に本人として入っていれば影響は小さい）。「繰り越せばいい」を無料の選択肢として扱わない。
   - 課税口座の配当等を入れ忘れると、損出しの効果を小さく、益出しの余地を大きく見積もる。配当があるか確認する。
   - その銘柄を「もともと手放したかった」なら、損出しは繰り延べ以上の意味がある（売る理由がすでにある）。
     ただし売った後に何を買うかは independence と目標配分（`nextbuy`）が先。
   - NISA の含み損は対象外（通算できない）。売っても税は減らず、枠が戻るのは翌年。
3. **評価できなかった保有**（価格が取れない・取得時の為替が無い）は、そのまま伝える。推測で埋めない。
   取得時の為替は `transactions --write-derived` で出せることを案内する。
4. 期限: 税は**受渡日**の年で決まる。年内に受け渡される最終売買日は証券会社の案内で確認してもらう（日付を推測で言わない）。
   特定口座では、同じ日に同じ銘柄（株式・ETF）を売買すると約定の順に関係なく「買いが先」とみなされ、損益が一部しか
   確定しない（益出しも同じ）。買い戻すなら翌営業日以降。日本株は T+2、米国株は国内受渡が約定日から 3 営業日目。
5. 売る・買い戻す前に `/before-trade` を通す。**買い戻しは購入なので DESC と事前承認が先**。
   出力で「買い戻しは不可」の銘柄は、損を確定させるとその銘柄は持たなくなる、と明確に言う。
6. 実発注はしない。売買するかどうかはユーザーが決める。
